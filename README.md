## 🚀 Featured Project

### ⚡ Non-Isolated AC-DC Power Module

**230V AC → ~5V DC Power Supply**

A practical AC-DC power module designed using **KiCad**, covering circuit design, PCB layout and hardware implementation.

### 🔧 Design Flow

```text
230V AC
   │
   ▼
┌─────────────────────┐
│ Capacitive          │
│ Voltage Dropper     │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│ Bridge Rectifier    │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│ Filtering Stage     │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│ Zener Regulation    │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│ 7805 Regulation     │
└──────────┬──────────┘
           │
           ▼
         ~5V DC
```

### 🛠️ Technologies & Tools

* KiCad
* PCB Design
* Circuit Design
* AC-DC Conversion
* Bridge Rectification
* Filtering
* Zener Regulation
* 7805 Voltage Regulation
* PCB 3D Visualization

### ⚠️ Safety

This is a **non-isolated mains-powered design**. The output is not galvanically isolated from the 230V AC input and must be treated as a hazardous-voltage circuit.
